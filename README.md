# Kohaku Roleplay

面向 [KohakuTerrarium](https://github.com/Kohaku-Lab/KohakuTerrarium) 桌面单用户的酒馆角色卡与多角色互动小说扩展（兼容 KT v2.2.2+）。支持单卡酒馆扮演、多卡群像小说创作及已有 Agent 的人物形象挂载；角色卡与世界书跨局共享，剧情与状态按会话独立存档。

## 核心特性

- **单卡酒馆扮演**：支持导入 PNG / JSON（V1–V3）与 `.charx` 角色卡、绑定世界书、切换开场白，在可拖拽缩放的 **Play** 小浮窗查看状态与常用操作，在 **role** 面板管理世界书、诊断及隔离的作者网页。
- **多卡群像小说与全屏书页**：可选「扮演主角」或「上帝群像导演」视角，特权主节点与各登场角色均按真名创建独立节点；内置中文默认旁白卡（可复制入库二创）与独立文风卡槽，提供羊皮纸／素白／夜间全屏书页阅读器、划词局部精修、双模式整幕重写与平行版本切换。
- **后续剧情走向提示**：酒馆与小说默认开启可随时切换的剧情分支卡，自动给出 3～4 个带倾向标签的不同走向，支持**一键直发**或**填入输入框微调后再发**。
- **长局高命中 KV 缓存**：单卡酒馆、小说主节点与各 NPC 均采用「静态底座锁死队头 + 实时状态瞬态置尾」组装，在动态世界书、属性面板与 MVU 频繁更新时保持历史对话前缀逐字节稳定。
- **原生玩法与旧卡兼容**：既支持免脚本的声明式状态、背包／任务面板与独立玩法包，也提供受限的旧卡 MVU 变量、卡片脚本、离线模块链接与作者状态页适配。

## 安装与快速开始

在运行原版 **KohakuTerrarium** 的环境中执行安装并重启应用（已具备依赖时可加 `--no-deps`）：

```sh
kt install .
```

1. 打开 **Roleplay Library** 标签页（或从设置页 **Roleplay Cards** 进入），导入本地角色卡（也可直接使用示例卡 [物资登记员](examples/native-ledger.json)），同时可在 **Worldbook Library** 导入世界书。
2. **开始酒馆**：选中单张角色卡，选择开场白与玩家设定后点击开局；在会话右下角打开 **Play** 查看实时状态，打开 **role** 配置世界书或查看作者网页。
3. **开始小说**：在角色库勾选一张或多张登场卡组建剧组，选择视角模式、旁白／文风卡、世界书与序章后点击开局，即可自动进入全屏沉浸书页工作台。

### 更新与备份

更新前请停止应用并备份 KT 配置目录（默认 `~/.kohakuterrarium`）与会话目录：本地安装重新执行 `kt install .`，Git 安装执行 `kt update kohaku-roleplay`。更新后直接从历史记录恢复旧会话即可，无需重新导卡或重开旧局。可选的 Node.js 22.12+（在已安装插件目录执行一次 `npm ci --ignore-scripts --omit=dev`）仅用于特定旧卡的离线模块链接，普通游玩与小说模式无需安装。

## 三种模式说明

### 1. 单卡酒馆（Tavern）

由单个角色节点演绎场景与人物，开场白直接写入会话历史而不消耗模型请求。支持卡内与附加世界书联动、立绘表情差分、CHARX 剧情切图、原生属性／任务面板及受限的旧卡 MVU 结算。

### 2. 多卡群像小说（Novel）

- **双视角与双文风槽**：**扮演主角**模式下主节点以主角名创建并维护主角属性表；**上帝群像导演**模式下主节点命名为 `旁白视角`，接收全知镜头与冲突调度。默认挂载内置「沉浸小说旁白」卡，并可额外指定一张**文风卡**叠加遣词质感；各登场卡的独立 `first_mes` 自动忽略以避免多卡冲突。
- **按需传唤与动态扩编**：日常过场由主节点直接成文；涉及多方博弈时并发唤醒在场角色提交台词、拟做动作与私有反应后统一裁定，幕间还可从卡库拉入新角色或即兴创建原创角色（支持一键收录入库）。每名角色维护动态属性表与三层私有记忆（印象、目击事实、主观推测）。
- **全屏书页与修订工作台**：点击会话右下角书本图标 **Novel Reader**（或 **Play** 顶栏按钮）随时展开全屏书页，按 `Esc` 或「返回会话」切回聊天。支持本地上传章节插图与角色头像、**拉选正文滑出局部精修栏**（独立 `fork_llm` 候选改写或手动直改），以及最新幕的**仅导演重执笔**（零额外 NPC 调用）与**回滚状态整幕重演**（最多保留 6 个平行版本通过 `< 1 / N >` 原子切换）。

### 3. 人物形象挂载（Persona）

在任意普通 Agent 的插件列表启用 `roleplay` 并在面板确认卡片形象，即可在不改变原有任务、工具权限与输出格式的前提下注入角色自称与说话口吻。

## 剧情走向提示

新开酒馆与小说默认启用「剧情走向提示」，也可在开局表单、**Play**、**role** 或小说书页顶栏随时一键开关：

- 点击走向卡片主按钮直接作为下一回合输入发送（带防重锁，避免连点拼接）；
- 点击卡片上的「微调」按钮可将完整行动词填入输入框（或聊天卡片内联草稿框），修改补充后再发送。
